# BÀI TẬP 02: LEARNINGAPP

## 1. Giới thiệu
Xây dựng ứng dụng LearningApp bằng React Native và Expo, hiển thị thông tin sinh viên, thống kê khóa học và danh sách môn học.

## 2. Link Expo
[- Link ứng dụng: DÁN_LINK_EXPO_VÀO_ĐÂY](https://snack.expo.dev/@thanhphuc79/learningapp)

## 3. Các Component
- **Header:** Hiển thị lời chào và thông tin sinh viên.
- **StatCard:** Thống kê khóa học.
- **CourseCard:** Hiển thị danh sách môn học và tiến độ học tập.
- **BottomMenu:** Thanh menu cuối màn hình.
- **App.js:** Kết hợp các component thành trang Home.
